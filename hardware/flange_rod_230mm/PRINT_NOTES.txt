xArm 7 전체 플랜지 + Ø30 반구 끝 원기둥 — 전체 길이 230 mm

파일
  xarm_flange_rod_d30_total230.stl  : Bambu Studio 출력용, mm 단위
  xarm_flange_rod_d30_total230.step : 정확한 곡면을 가진 단일 솔리드 CAD
  xarm_flange_rod_d30_total230.scad : 수정 가능한 OpenSCAD 형상 소스
  parameters.json / build_cad.py  : 공통 치수 및 CAD/검증/미리보기 재생성
  preview.png                    : 형상 및 치수 도면
  geometry_checks.json           : CAD/메시/단면 검증 결과

길이 기준 — 최종 요청 반영
  로봇 플랜지에 닿는 판 아래면 z=0부터 가장 먼 끝 z=230까지 총 230.
  전체 원판: Ø78, 두께 4. 판 윗면 z=4.
  원기둥: Ø30. 판 윗면부터 반구 시작점까지 211.
  반구: R15. 시작 z=215, 끝 z=230. 완전한 반구로 원기둥에 매끄럽게 이어짐.
  판 윗면부터 끝까지 돌출 길이는 226.
  판과 원기둥은 일체형. 원기둥 뿌리에 R2 필렛 적용.
  CAD는 내부에 빈 공간이 없는 솔리드. 실제 내부 충전은 슬라이서 인필로 결정.

장착 치수 — 출력 성공한 1/4 시험편과 동일
  PCD50 위 45°, 135°, 225°, 315°에 4개 홀.
  구멍 중심 X/Y = ±17.67767.
  관통 홀 Ø6.6, 접시머리 자리 Ø12.8 / 90°, 깊이 3.1.
  아래쪽 직선 홀 구간 0.9.
  M6×8 십자 접시머리 나사 4개 사용. 길이 8은 머리 포함.
  머리 윗면이 판 표면과 같으면 플랜지 안으로 4 mm 돌출.
  더 깊이 앉으면 돌출량이 증가하므로 실제 나사로 확인.
  접시자리 안쪽과 R2 필렛 바깥쪽 사이 최소 간격 1.6.
  나사 중심과 원기둥 직선부 측면 거리는 10. 두꺼운 드라이버 손잡이는
  원기둥에 닿을 수 있으므로 실제 공구가 접근 가능한지 체결 전에 확인.
  중앙 위치결정 돌기/핀은 추가하지 않았음.

Bambu P1S / PETG 출력
  STL을 배율 100%, mm로 불러오고 78×78×230 크기를 확인.
  판의 넓은 평평한 아래면을 베드에 놓고 원기둥은 수직, 둥근 끝은 위.
  이 방향은 형상상 서포트가 필요하지 않음.
  기본 출력 높이 250보다 20 mm 낮으므로 높이 프로필 변경 불필요.
  베드 중앙에 배치. 선택된 실제 P1S 노즐과 PETG 필라멘트 프로필을 사용.
  0.4 mm 노즐 기준 시작 설정 제안:
    레이어 0.20 mm, 벽 6줄, 상/하단 6층, Gyroid 인필 40%.
    서포트 끔, 래프트 끔. 베드 접착이 부족할 때만 외부 브림 5 mm 추가.
  위 설정은 시작점이며 강도 보증값이 아님. 온도/유량은 실제 PETG 제품
  프로필과 제조사 안내를 사용. 기존 시험편에서 잘 된 PETG 프로필 유지 가능.
  필라멘트 Ø1.75±0.05 표기는 원재료 지름이므로 CAD 배율을 변경하지 않음.
  이번 작업에는 슬라이싱, 프린터 전송 또는 출력 시작을 포함하지 않음.

확인 범위
  CAD 단일 솔리드/유효성, STEP 재입력, STL 밀폐/방향/크기,
  네 체결 홀, 원기둥, R2 필렛, R15 반구 단면과 부피를 자동 검증.
  1/4 시험편의 끼움 성공은 반영했으나 4홀 완성품의 실물 적합성 및
  긴 원기둥의 횡하중/충격/층간 강도는 검증하지 않음.
  설계상 팁 위치는 플랜지 좌표계에서 (0, 0, 230) mm.
  로봇 TCP/하중 설정은 변경하지 않았으며 실물 치수와 질량을 측정한 뒤 사용.

재생성
  Python 의존성: cadquery, trimesh, numpy, scipy, matplotlib
  python build_cad.py
  parameters.json 편집 후 재생성. STEP과 STL은 CadQuery에서 생성하며,
  SCAD는 동일 치수를 표현하는 별도 편집용 소스(곡선 다각형 근사)임.
